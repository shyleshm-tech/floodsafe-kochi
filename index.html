🎓 How the prototype works

The user selects a starting location on the map and enters an emergency destination.

The routing engine attempts to return multiple road alternatives.

For each available route, the system calculates:
Route Cost = Distance + Flood-Risk Penalty

The route with the lowest calculated cost is highlighted as the proposed safest route.

⚠️ Flood-risk values in this demonstration are simulated. They should be replaced with real flood-depth, road-closure, or water-level data for a real emergency system.
